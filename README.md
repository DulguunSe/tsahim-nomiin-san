# 📚 Цахим номын сан

Сургуулийн сурагч, багш нарт зориулсан **цахим номын сангийн вэб апп**.
Номын санч, багш нар PDF ном оруулж, сурагчид хөтөч дээрээ хайж, онлайн уншиж,
татаж авна.

## Боломжууд

**Сурагч, багш нарт:**
- Номын нэр, зохиогч, түлхүүр үгээр хайх (том, жижиг үсэг ялгахгүй)
- Ангилал (Уран зохиол, Математик…) болон ангиар (1–12-р анги) шүүх
- Шинээр нэмэгдсэн / нэрээр (монгол цагаан толгойн дарааллаар) / их уншигдсанаар эрэмбэлэх
- PDF номыг хөтөч дээр шууд унших эсвэл татаж авах
- Ижил ангиллын номуудын санал болголт
- Гар утас, таблет, компьютерт тохирсон дизайн

**Админ (номын санч, багш)-д:**
- Нууц үгээр нэвтрэх
- Ном нэмэх, засах, устгах (PDF файл эсвэл гадны холбоос, нүүр зураг)
- Нүүр зураг оруулаагүй бол номын нэрээр өнгөт нүүр автоматаар үүснэ
- Нийт ном, үзсэн, татсан тооны статистик

## Суулгах

### 1. Node.js суулгах

[nodejs.org](https://nodejs.org) сайтаас **Node.js 22.13 буюу түүнээс шинэ** (LTS)
хувилбарыг татаж суулгана. Шалгах:

```bash
node --version
```

### 2. Төслийг татаж, хамаарлуудыг суулгах

```bash
git clone https://github.com/DulguunSe/tsahim-nomiin-san.git
```

```bash
cd tsahim-nomiin-san
```

```bash
npm install
```

### 3. Тохиргоо хийх

`.env.example` файлыг `.env` нэрээр хуулаад, доторх утгуудыг өөрчилнө:

```bash
cp .env.example .env
```

```ini
SCHOOL_NAME=Манай сургууль
ADMIN_PASSWORD=энд_хүчтэй_нууц_үг_бичнэ
```

> ⚠️ `ADMIN_PASSWORD` тохируулаагүй бол түр хугацаанд `admin123` нууц үг
> ажиллана. Бусдад нээхээсээ өмнө заавал өөрчилнө үү.

### 4. Ажиллуулах

```bash
npm start
```

Хөтөч дээр **http://localhost:3000** хаягийг нээнэ. Админ хэсэг:
**http://localhost:3000/admin**

Туршиж үзэхийн тулд 8 жишээ ном нэмж болно (дараа нь админ хэсгээс устгана):

```bash
npm run seed
```

## Сургуулийн сүлжээнд бусдад нээх

Хамгийн хялбар арга бол сургуулийн нэг компьютер (эсвэл сервер) дээр ажиллуулах.
Сервер асах үед консолд дараах мэдээлэл гарна:

```
📚 Манай сургууль — цахим номын сан ажиллаж байна
   Энэ компьютер дээр:  http://localhost:3000
   Бусад компьютерээс:  http://192.168.1.25:3000
```

Нэг сүлжээнд (Wi-Fi) холбогдсон сурагч, багш нар **"Бусад компьютерээс"** гэсэн
хаягаар орно. Windows-ийн Firewall зөвшөөрөл асуувал "Allow" дарна.

## Интернэтэд үнэгүй нээх (сургуулийн компьютер + Tailscale)

Сургуулийн нэг компьютер дээр ажиллуулж, **Tailscale Funnel**-ээр
`https://nomiin-san.….ts.net` маягийн тогтмол хаягтай интернэтэд гаргана.
Карт, домэйн хэрэггүй, бүрэн үнэгүй.

👉 Алхам алхмаар заавар: **[docs/surguuliin-kompyuter.md](docs/surguuliin-kompyuter.md)**

Windows-д зориулсан бэлэн скриптүүд:
- `scripts\windows\start.bat` — давхар дарж серверийг асаана.
- `scripts\windows\autostart.ps1` — компьютер асахад сервер автоматаар асдаг болгоно.

## Төлбөртэй хостинг (Render)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/DulguunSe/tsahim-nomiin-san)

Төсөлд `render.yaml` тохиргоо бэлэн байгаа тул хэдхэн алхмаар байршуулна:

1. [render.com](https://render.com) сайтад **GitHub бүртгэлээрээ** нэвтэрнэ.
2. Дээрх **Deploy to Render** товчийг дарна.
3. Гарч ирэх маягтад **SCHOOL_NAME** (сургуулийн нэр) болон **ADMIN_PASSWORD**
   (админы хүчтэй нууц үг)-ийг бичнэ.
4. Төлбөрийн карт холбоод **Deploy Blueprint** дарна.
5. 3–5 минутын дараа `https://tsahim-nomiin-san.onrender.com` маягийн хаяг гарна
   (нэр давхцвал өөр байж болно). `/admin` хаягаар нэвтэрч ном нэмнэ.

**Үнэ:** Starter сервер сард ~$7 + 1 ГБ диск ~$0.25. Номын PDF-үүд дискэнд
хадгалагддаг тул үнэгүй багц тохирохгүй — үнэгүй сервер дахин асах бүрт
оруулсан файлууд устдаг. Диск дүүрвэл Render-ийн тохиргооноос томруулж болно.

GitHub дээрх үндсэн branch-д өөрчлөлт push хийх бүрт Render автоматаар
шинэчилнэ. Өөрийн домэйн (жишээ нь `nomsan.manai-surguuli.mn`)-ыг Render-ийн
**Settings → Custom Domains** хэсгээс холбож болно.

### Бусад хостинг

`Dockerfile` бэлэн тул Railway, Fly.io, VPS зэрэг Docker дэмждэг хаана ч
ажиллана. Анхаарах зүйл:

- Байнгын диск (volume)-ийг `/data` руу холбоно (эс тэгвээс номууд устна).
- `ADMIN_PASSWORD` орчны хувьсагчийг заавал тохируулна.
- HTTPS proxy-ийн ард бол `TRUST_PROXY=1` болон `COOKIE_SECURE=1` болгоно.

## Тохиргооны хувьсагчид

| Хувьсагч         | Тайлбар                                           | Анхдагч утга       |
|------------------|---------------------------------------------------|--------------------|
| `SCHOOL_NAME`    | Сайтын толгойд харагдах сургуулийн нэр            | `Манай сургууль`   |
| `ADMIN_PASSWORD` | Админ хэсгийн нууц үг                             | `admin123` (түр)   |
| `PORT`           | Серверийн порт                                    | `3000`             |
| `MAX_UPLOAD_MB`  | Нэг файлын дээд хэмжээ (МБ)                        | `100`              |
| `DATA_DIR`       | Мэдээллийн сан, файлууд хадгалагдах хавтас        | `./data`           |
| `TRUST_PROXY`    | Nginx/Render зэрэг proxy-ийн ард бол `1`           | —                  |
| `COOKIE_SECURE`  | HTTPS хаягаар ажиллаж байвал `1`                   | —                  |

`NODE_ENV=production` үед `ADMIN_PASSWORD` заавал шаардлагатай.

## Нөөц хуулбар (backup)

Бүх мэдээлэл `data/` хавтсанд хадгалагдана:

```
data/
├── library.db          ← номын мэдээлэл (SQLite)
└── uploads/
    ├── books/          ← PDF файлууд
    └── covers/         ← нүүр зургууд
```

Тогтмол хугацаанд (жишээ нь долоо хоног бүр) серверээ зогсоогоод `data/`
хавтсыг бүхэлд нь флаш эсвэл Google Drive руу хуулж хадгална уу.

## Төслийн бүтэц

```
server.js              ← серверийг асаах
src/
├── app.js             ← Express апп, аюулгүй байдлын тохиргоо
├── config.js          ← .env тохиргоо унших
├── db.js              ← SQLite мэдээллийн сан, хайлт
├── helpers.js         ← загварт ашиглах туслах функцууд
├── upload.js          ← PDF, зураг хүлээн авах, шалгах
└── routes/
    ├── public.js      ← нүүр хуудас, номын хуудас, унших, татах
    └── admin.js       ← нэвтрэх, ном нэмэх/засах/устгах
views/                 ← EJS хуудасны загварууд
public/                ← CSS, JavaScript, дүрс
scripts/seed.js        ← жишээ өгөгдөл нэмэх
test/                  ← автомат тестүүд
```

## Аюулгүй байдал

- Админ нууц үг, нэвтрэх оролдлогын хязгаар (15 минутад 10 удаа)
- Бүх маягтад CSRF хамгаалалт
- Оруулсан файлын төрлийг өргөтгөл болон агуулгаар нь (PDF/JPG/PNG/WEBP) шалгана
- Content-Security-Policy болон бусад хамгаалалтын HTTP толгойнууд

## Зохиогчийн эрх

Номын санд зөвхөн сургууль түгээх эрхтэй номуудыг (өөрсдийн бэлтгэсэн
гарын авлага, нийтийн өмчид шилжсэн бүтээл, зохиогчийн зөвшөөрөлтэй ном г.м.)
оруулна уу.

## Цаашид нэмж болох санаанууд

- Багш бүрт тусдаа админ эрх
- Сурагчид нэвтэрч уншсан номоо хадгалах, үнэлгээ өгөх
- Биет номын зээлдүүлэлт бүртгэх
- Номын санг зөвхөн сургуулийн хэрэглэгчдэд хаалттай болгох
